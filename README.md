# 💻 Laptop Troubleshooting Expert System

A rule-based expert system developed using Python and Flask to diagnose common laptop issues based on user-reported symptoms.

---

## 📌 Overview

This project is an interactive web-based application that simulates an **expert system** for troubleshooting laptop problems. It collects user inputs in the form of symptoms and applies predefined rules to identify possible issues along with suggested solutions.

The system demonstrates how artificial intelligence concepts like **rule-based reasoning** and **decision-making systems** can be applied to real-world problem-solving.

---

## 🚀 Features

* 🔍 Symptom-based diagnosis
* 🧠 Rule-based expert system logic
* 📊 Confidence level calculation
* 🌐 Web-based interface using Flask
* 🎨 Modern dark-themed UI
* ⚡ Fast and lightweight

## ⚙️ Installation & Setup

### 1. Clone the repository

```
git clone https://github.com/your-username/laptop-expert-system.git
cd laptop-expert-system
```

### 2. Install dependencies

```
pip install -r requirements.txt
```

### 3. Run the application

```
python app.py
```

### 4. Open in browser

```
http://127.0.0.1:5000
```

## ☁️ Deployment (AWS EC2)

This project can be deployed on Amazon Web Services using Amazon EC2.

Steps:

* Launch EC2 instance (Ubuntu)
* Install Python and Flask
* Upload project files
* Run the app using:

```
python3 app.py
```

* Access using:

```
http://<public-ip>:5000
```

---

## 🧠 How It Works

1. User selects symptoms from the interface
2. System matches symptoms with predefined rules
3. If required conditions are met:

   * Issue is identified
   * Confidence level is calculated
4. Suggested solution is displayed

---

## 📊 Example Output

* Issue: Overheating
* Confidence: 75%
* Solution: Clean fan, use cooling pad
